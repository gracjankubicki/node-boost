# Astro 7 Compatibility Notes

Astro 7 requires Node `>=22.12.0`. Verify the package manager, CI image, local runtime, and deployment runtime all satisfy that floor.

- Astro 7 uses the Rust compiler and Vite 8. Do not add legacy compiler assumptions or rely on an older Vite plugin contract without checking compatibility.
- The HTML pipeline is stricter and `compressHTML` defaults to the JSX-oriented mode. Fix invalid markup at the source rather than weakening validation.
- Advanced routing and route caching are stable capabilities, but caching still must respect cookies, sessions, authorization, and other per-request state.
- `@astrojs/db` is no longer part of the Astro 7 path. Use the project's supported database integration instead of restoring a removed package.
- For Tailwind 4, use the Vite integration path; `@astrojs/tailwind` is deprecated for that version.
