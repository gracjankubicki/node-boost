# Astro Routing and Rendering

## When to use this skill

Use when adding routes, dynamic parameters, redirects, rewrites, pagination, i18n, SSR, or prerendering.

## Procedure

1. Identify whether the output depends on the request, then choose static generation, on-demand rendering, or an explicit mixed route.
2. Verify adapter and runtime support before using cookies, sessions, request headers, streaming, or server-only APIs.
3. Keep URL, parameter, canonical, redirect, and rewrite contracts explicit and validate external identifiers.
4. Test generated output and request-time output separately; include a browser smoke only when client navigation or partial pages are involved.
